Process Setting

Media Decryption with Keys

Keep your recordings encrypted in storage and still play them in PLAY: add the key once, switch Encryption on for the channel, and PLAY unlocks the media in your browser as you listen.

Settings→Process→a process→Encryption Keys

01

What this feature does

A short primer before you configure anything.

Recordings of some channels are stored encrypted, so only someone holding the key can listen to them. PLAY lets you save that key against the channel, and then:

  • checks each recording as it opens, from the file itself, to see whether it needs unlocking;
  • unlocks encrypted files in your browser and plays them — audio, video and waveform players alike;
  • plays ordinary files straight away, with no extra step.

The unlocked copy exists only in your browser while you listen. It is not saved or sent anywhere.

02

Set it up in two steps

Key first, then the switch.

Step 1 — save the key for the channel.

  1. Open Encryption Keys
    Go to Settings → Process, choose the process, and click Encryption Keys in the left menu. The table has one row per channel (Call, Chat, Video…).
  2. Add or edit the row
    Click Add key for a channel without a key, or the pencil icon to change one.
  3. Choose the algorithm
    Pick the algorithm the files were encrypted with (see the table below).
  4. Paste the key
    Paste it into Key. Tick Validate key format (optional) if you want PLAY to check its length before saving.
  5. Save
    Click Save. The key now shows masked, with only its last characters visible.

Step 2 — turn Encryption on for the channel.

  1. Open the channel’s storage settings
    In the process, open the channel (for example Call Channel Configuration).
  2. Click the pencil, then switch Encryption on
    The switch can only be turned on once the channel has a key — otherwise it shows Add an encryption key for this channel to turn this on.
  3. Save
    Save the channel. Recordings of this channel now play with the key.

03

Algorithms and keys

Which choice fits your files.

AlgorithmKey sizeNotes
AES-128-ECB16 charactersSimplest layout: the file is just the encrypted audio or video.
AES-256-ECB32 charactersSame layout, longer key.
AES-128-CBC / AES-256-CBC16 / 32 charactersThe file starts with a 16-byte starting value, followed by the encrypted media.
AES-128-GCM / AES-256-GCM16 / 32 charactersThe file starts with a 12-byte starting value and ends with a 16-byte check value.

The key can be written as plain text, as hexadecimal, or as base64 — whichever gives exactly the size in the table. Keys are stored encrypted and cannot be viewed again after saving; use the copy icon to copy one, or enter a new key to replace it. When editing, leave the key box empty to keep the current key.

04

Playing an encrypted recording

Nothing extra to do.

Open the recording as usual. PLAY looks at the start of the file: if it is an ordinary audio or video file it plays directly; if it is not, and the channel has Encryption on, PLAY unlocks it with the channel’s key and plays it.

Files recognised as ordinary media include wav, mp3, aac, ogg, flac, mp4, m4a, mov, webm, mkv, aiff, au and amr. They are never put through decryption, even when the channel has Encryption on — so a channel can safely hold a mix of encrypted and plain files.

05

If something goes wrong

What each message means.

What you seeLikely reasonWhat to do
Failed to decrypt audio fileThe key or algorithm does not match the one used to encrypt the file, or the file is damaged.Check the algorithm and key on the Encryption Keys page and save the correct one.
Audio / Media file not foundThe file could not be reached at its storage address.Check the channel’s storage address; this is not a key problem.
Plays, but the Encryption switch is onThe file was not encrypted, so PLAY played it directly.Nothing — this is expected.
Encryption switch cannot be turned onThe channel has no key yet.Add the key first, then switch it on.
Keep keys safe. Anyone with the key can unlock your recordings. Share it only with people who need it, and replace it if it may have been exposed.
