Process Version Setting

AI Criteria

Tell the rating AI exactly what evidence should earn each answer on a question — so scoring is explainable instead of a black box, and consistent across every review.

Settings→Process→Process Version→a question row

01

What this feature does

A short primer before you configure anything.

Every rating question already has an answer type — Yes/No, a numeric scale, a custom set of options. AI Criteria lets you attach a written checklist to each individual answer, describing what the AI should hear or read in the transcript before it's allowed to land on that answer.

For example, a "Did the agent verify the customer's identity?" question might carry:

  • Yes — "Agent asked for and confirmed name, DOB, and account number"; "Agent cross-checked the answer against account records"
  • No — "Agent skipped verification entirely"; "Agent accepted an unconfirmed answer"

Without criteria, the AI infers intent from the question text alone. With criteria, it grades against your own written standard — and shows its reasoning back to reviewers.

02

Where to find it

The panel lives inside the question row, not in a separate settings page.

Open Settings → Process → Process Version, expand a category, and either edit an existing question or add a new one. AI Criteria appears as its own panel directly beneath the question's Code / Text / Type / Weightage row — it's part of that same question editor, not a separate screen.

03

Configuring criteria

Walk through enabling the toggle and writing your first checklist.

  1. Open the question for editing
    Click the edit icon on the question row. The AI Criteria panel appears below the row once an answer type is selected.
  2. Turn on the AI Criteria switch
    Off by default. Until it's on, the panel just shows a hint — no criteria are collected or sent.
  3. Pick an answer option's tab
    Tabs list every option for the question's answer type (e.g. Yes / No). Criteria are written per option, not once for the whole question.
  4. Add criteria, one line at a time
    Type a criterion and press Enter or click the add button. Repeat for as many lines as the option needs, then switch tabs to cover the other options.
  5. Save the question
    The save action commits the question text and every criterion across all tabs together — not one tab at a time.

Good to know

Only the option you're currently viewing gets edited by the input box — switching tabs doesn't lose what you typed on another tab; it's held separately per option until you save.

04

Reading the status icon

The AI icon on a question row is a truth indicator, not a toggle mirror.

Once saved, questions with real criteria show a small AI icon in the actions column — click it to expand a read-only view of everything saved for that question, without entering edit mode.

Enabled ≠ configured

The icon only appears once at least one criterion has actually been saved on at least one answer option. Turning the switch on and saving with every list still empty does not light up the icon — it deliberately reflects real content, not just the flag.

05

Editing, removing, and unsaved drafts

Nothing you type gets silently discarded.

  • Remove a criterion — click the ✕ next to any line in the current tab. It's removed from that option's list immediately (still needs Save to persist).
  • Close without saving — if every input box is empty, the panel just closes and reverts to the last saved state.
  • Close with text still typed — if you've typed a criterion but haven't clicked add, closing prompts: "You have a criteria that has not been added yet. Add it and save now?" Confirming folds that text in and saves; you're never forced to choose between losing it and re-opening the editor.

06

Draft vs. published versions

Criteria can be updated in both — the rest of the question can't.

On a draft version, every field is editable: code, text, answer type, weightage, and AI Criteria. On a published version, the question's code, answer type, and weightage are locked — but its text and AI Criteria can still be updated in place, so criteria can be refined after a process has gone live without cutting a new version.

07

What reviewers see

Criteria don't just steer the score — they show up in the reasoning.

On the recording detail page's AI Ratings panel, each answer already shows a confidence percentage with collapsible evidence. When AI Criteria is configured on that question, the AI's stated reason for matching your criteria appears alongside the transcript evidence in that same expandable panel — so a reviewer can see exactly which of your written criteria the AI judged as met.

Field reference

For anyone integrating with or reading raw question/rating data.

FieldLives onDescription
aiCriteriaEnabled Question Whether the AI Criteria switch is on for this question. Saved independently of whether any criteria exist yet.
aiCriteria Question Map of answer-option value → list of criteria strings, e.g. { yes: [...], no: [...] }. Cleared to {} whenever the switch is off at save time.
criteriaAnswer AI rating response The AI's stated justification against your criteria for a given answer, shown next to transcript evidence on the AI Ratings panel.
